# {작업 제목} — 결정·확인 요청

> 소유: 구현 세션(TASK_RESULT를 고칠 때마다 함께 고친다) · 독자: 책임자
> 원칙: 책임자가 이 문서만 보고 **승인 / 다시 확인 / 거절**을 바로 고를 수 있게 쓴다.
> 코드·파일·함수 이름, 하네스 용어(AC-n, FR-n, Blocker/Major/Minor, 라운드, 게이트, 세션 이름), 커밋 번호, 문서 경로를 쓰지 않는다. 단, 승인 대상인 커밋 메시지는 그대로 보여 준다.
> 지난 내용을 쌓지 않고 **지금 상태만** 남긴다. 판단이 끝난 항목은 "지금까지 된 것"에 한 줄로 옮긴다.

| 항목 | 내용 |
|---|---|
| 마지막 갱신 | YYYY-MM-DD HH:MM |
| 지금 단계 | (예: 고친 내용을 저장하기 전, 승인 대기) |
| 결정 및 판단 이슈 현황 | 결정 요청사항 합계: {총 판단 항목 수} \| 결정 및 완료✅ : {완료된 항목 수} \| 미결정🔴 : {판단·결정 전 항목 수} |

> 답하는 법: 항목 번호와 답만 주면 된다(예: "1 승인, 2 A, 3 확인 완료")

## 지금 판단할 것

> 답이 필요한 항목이 없으면 이 절에 "없음 — (지금 진행 중인 일 한 줄)"만 남긴다.
> 항목 제목 앞에 필요한 답의 종류를 붙인다: **[승인]** 승인 / 다시 확인 / 거절 · **[선택]** 선택지 중 하나 · **[확인]** 직접 확인 후 결과
> 각 항목의 본문은 표로 쓴다(왼쪽 열 = 항목, 오른쪽 열 = 내용). 한 칸에 여러 줄이 필요하면 `<br>`로 줄을 나눈다. 캡처·긴 커밋 본문은 표 아래에 둔다.
